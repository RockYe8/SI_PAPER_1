# 03 — Wrong Book / 错题本 page

**What to build:** Add a visible `Wrong Book / 错题本` entry on the homepage and a page where learners can review saved wrong questions from the current browser. The page joins local wrong book records with the current exam bank to show the latest question text, options, correct answer, explanation, and source.

**Blocked by:** 01 — Wrong Book local state; 02 — Capture wrong book records after exam submission.

**Status:** ready-for-agent

- [ ] Homepage shows a clear `Wrong Book / 错题本` button.
- [ ] Wrong book page lists saved items grouped or labelled by batch and question number.
- [ ] Each item shows wrong count, latest selected option, correct answer, and latest status.
- [ ] Each item shows the latest question text, Explanation, and Source from the current exam files.
- [ ] The page explains that records are saved in this browser only.
- [ ] Learners can remove one item.
- [ ] Learners can clear all wrong book records.
- [ ] Empty state is shown when there are no saved wrong questions.
- [ ] No wrong-question-only practice mode is added in this version.
